# IELTS Focus Mobile

Private, installable IELTS study PWA.

- App code lives in this repository.
- The deployed site is owner-only and requires the owner's ChatGPT sign-in.
- PDFs and MP3 files are hosted with the deployment and loaded only when opened or played.
- The service worker caches only the small app shell; it deliberately does not cache whole PDF/audio libraries.

Large copyrighted study materials are not committed to GitHub.
